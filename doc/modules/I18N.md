# Internationalization

Supports French (`fr`), English (`en`), and Arabic (`ar`). Arabic uses RTL layout. Default locale is `fr`.

## Configuration

- Locales and direction helpers: `src/i18n/config.ts`
- next-intl request config (locale from cookie): `src/i18n/request.ts`
- Dictionaries: `src/i18n/dictionaries/`
- Locale cookie name: `vestio_locale` (1-year expiry, set client-side by `LanguageSwitcher`)

## Usage

Server components: `getTranslations()` from `next-intl/server`.  
Client components: `useTranslations()` from `next-intl`.  
Current locale — server: `getLocale()`, client: `useLocale()`.

## RTL

Root layout sets `dir={localeDirection(locale)}` on `<html>`. Use logical CSS utilities (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`) everywhere. Use `rtl:` only for genuine directional exceptions.

## Adding translations

Add keys to both `fr` and `ar` dictionaries. Test the UI in both locales and verify RTL layout in Arabic.
